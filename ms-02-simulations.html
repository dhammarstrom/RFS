14  Describing mathematical models and doing simulations

We started this section by exploring how to create DAGs. Such models do not, in their basic form, contain magnitudes or forms of relationships between variables. For example, an exposure could affect an outcome in different ways, including negative or positive linear or nonlinear associations. Additionally, the variables themselves can take on different scales and types, such as binary, count, or continuous variables. Measured variables can also be thought of as descendants of an unobserved data-generating process that, together with a measurement process, creates the observed variable. To go beyond describing causal relationships across variables, we might want to mathematically characterize these relationships and explore model implications using simulations. The purpose of this chapter is to first describe a system for setting up mathematical notation in quarto documents. Next, we will introduce, with a simple example, how we can translate mathematical notation or a DAG into code to perform a data simulations.

14.1 Mathematical notation

14.1.1 \(\LaTeX\)

\(\LaTeX\) is a typesetting system used for preparing technical documents and, popularly1, typesetting mathematical notation. Quarto accepts \(\LaTeX\) math syntax inline and as a display math. Inline syntax could look like this: $F = m \times a$, which renders into \(F = m \times a\). Display math requires:

$$
F = m \times a
$$

Which will place the output on its own line, in the middle of the document:

\[ F = m \times a \]

LaTeX syntax contains all the arithmetic operator symbols (e.g., \(+\quad-\quad/\quad*\quad(\quad)\quad\)). Additionally, symbols for greek letters, arrows, binary operators and set notation are available as commands, such as \alpha \rightarrow \leq \in, producing \(\alpha \rightarrow \leq \in\).

The Greek alphabet is often used for describing parameters in mathematical notation (Table 14.1). However, different conventions exists in different fields and traditions.

14.1.1.1 Formatting notation

We can use colors to, e.g., highlight parts of an equation using curly brackets {}:

$$
y = {\color{red}x^2} + x
$$

\[ y = {\color{red}x^2} + x \]

When using text to define an operator, e.g., to describe the normal distribution with its parameters, we can use \operatorname{Normal} to get the text-part correctly formatted, i.e., \(\operatorname{Normal}(\mu, \sigma)\), instead of \(Normal(\mu, \sigma)\). In addition of establishing your own operators, specific operator exists for a set of commonly used mathematical operators (Table 14.2).

Instead of \operatorname, the \text operator can be used to declare what is intended to be text as text. We might want to write “5 cars”, this could be accomplished using 5 \text{cars} (\(5 \text{cars}\)), instead of 5 cars (\(5 cars\)). Although the text-operator does not format the text as expected in the math environment we still loose a space. This can be added inside the text operator (5 \text{ cars}: \(5 \text{ cars}\)). This behavior has consequences when we use text instead of a custom operator. E.g., a \log b will correctly place spaces between operators and variables but a \text{log} b will not (\(a \log b\), vs. \(a \text{log} b\)).

Superscripts and subscripts are common features of mathematical notation indicating e.g., power and indices. For example the ith element of the vector x can be written as \(x_i\) using the syntax x_i. When additional information needs to go into the indices we can add the next level index in brackets, to accomplish this we use curley brackets to indicate what should be included as subscript, e.g., x_{i[j]} becomes \(x_{i[j]}\).

14.1.2 Describing a model

A statistical model can be written as a formula over multiple lines. For example, to describe a parametric model using the normal distribution to connect parameters to data, we can start by defining this assumption, i.e., \(y \sim \operatorname{Normal}(\mu, \sigma)\). Next we might want to describe how μ relates to a variable, x, i.e. \(\mu = \alpha + \beta x\). This approach separates the distributional assumption from the deterministic model. To write all this in latex we can use the align environment2.

The syntax described below uses \\ as line breaks and & to align signs.

$$
\begin{align}
y &\sim \operatorname{Normal}(\mu, \sigma) \\
\mu &= \alpha + \beta x 
\end{align}
$$

\[ \begin{align} y &\sim \operatorname{Normal}(\mu, \sigma) \\ \mu &= \alpha + \beta x \end{align} \] We can read the resulting formula as “y is distributed following a normal distribution with mean μ and standard deviation σ. μ is linearly related to x through an intercept α and a slope β”.
